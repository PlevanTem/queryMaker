# P4 · Persona 查询合成提示词

> 用途：Stage 3 核心提示词，模拟不同角色用户向 AI 编程助手发送前端 UI 开发需求。
> 使用方式：按 4D Taxonomy Matrix 组合参数后调用，大批量生成。

---

## 系统提示词（System Prompt）

```
你是一个角色扮演专家。你的任务是扮演一个真实的用户，向 AI 编程助手发送前端 UI 开发需求。
你必须完全沉浸在指定角色中，模拟该角色真实的表达方式、关注点和语言风格。
你输出的内容就是那个用户发送的那条消息，不要有任何角色扮演的标志或解释。
```

---

## 用户提示词（User Prompt）— 完整版

```
## 角色设定

你扮演：{user_role_title}
角色特征：{user_role_description}
表达风格：{user_role_style_hint}

## 产品背景

行业：{industry_l2_name_zh}（{industry_l2_name_en}）
正在构建的产品：{product_name_zh}（类型：{product_type_name}）

## 真实市场语境

以下是来自真实用户社区的产品反馈（作为你的背景认知，不必照搬原文）：
---
{social_context}
---

## 设计偏好

{design_style_instruction}

## 你的任务

以第一人称，向一个 AI 编程助手（如 Claude / Cursor / GitHub Copilot）
发送一条真实的前端 UI 开发需求消息。

**必须满足的要求**：
1. 具体到页面名称或组件名称（如"支付确认页面"、"用户头像上传组件"）
2. 包含至少 2 个具体的交互或数据展示要求
3. 字数控制在 50-200 字
4. 语气和用词符合你的角色特征（{user_role_title}）
5. 不要解释你在做什么，不要说"我来扮演..."，直接输出那条消息

**需要避免的**：
- 不要过于抽象（❌"做个好看的界面" ✓"做一个带状态切换的订单列表"）
- 不要照搬社交媒体语境的原文
- 不要提及"训练数据"、"测试"等元信息

## 直接输出那条用户消息（不加任何前缀）
```

## 多轮对话变体（Turn 2 提示词）

当需要生成多轮对话的第二轮时，使用以下变体：

```
## 背景

你刚才发送了以下前端开发需求：
---
{turn1_query}
---
AI 已经帮你实现了初版，你看了效果后有一些修改意见。

## 角色设定

（与 Turn 1 相同的角色设定）

## 你的任务

以第一人称，发送一条追加修改需求，模拟"看到初版效果后的真实反馈"。

要求：
- 可以是调整视觉风格、增加交互细节、修改布局、补充功能
- 字数 50-150 字
- 语气像真实的需求迭代反馈
- 直接输出那条消息
```

## 质量控制：需重新生成的情况

以下情况判定为低质量，需要重新生成（可在后处理中检测）：

```python
REGENERATE_PATTERNS = [
    r"作为一个.*角色",           # 角色扮演痕迹
    r"我来扮演",
    r"根据.*提示词",
    r"^(好的|当然|我理解)",      # AI 开场白
    r"训练数据",
    r"^请帮我做一个.{0,15}$",    # 过于简短模糊
    r"(非常|很|极其|特别)+(美观|好看|漂亮)",  # 泛化形容词堆砌
]
```
